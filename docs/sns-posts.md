# SNS投稿の台本

本書は、SNS戦略(docs/sns.md)が定めた最初の30日ぶんの投稿を、そのまま撮って出せる形にしたものである。戦略と柱の考え方は docs/sns.md にあり、ここにあるのは実際に画面へ載せる言葉とカットの並びである。

## 共通の決めごと

| 項目 | 決めごと |
| :-- | :-- |
| 尺 | 15〜30秒。あるある系だけ10〜20秒 |
| 画面の向き | 縦(9:16) |
| 素材 | アプリのサボリーヌをそのまま使う。動画専用の作画はしない |
| テロップの位置 | 画面の中央より少し上。TikTokの操作ボタンと重ならない高さに収める |
| 話し言葉 | 「〜だよ」「〜なんだ」のやわらかい調子。断定と説教をしない |
| 締め | 「プロフィールのリンクから、里親になれるよ」をテロップと固定コメントの両方に置く |
| リンク | https://saborine.yjn279.workers.dev(TikTok用・Instagram用でパラメータを分ける) |
| 音源 | そのとき伸びている音源に合わせる。特定の曲を前提にした構成にしない |

投稿前に毎回1つだけ確かめる。「これを、招待される側の人が見たときに、責められたと感じるか」。感じる可能性があるなら出さない。

## 素材の作り方

サボリーヌの姿は5つある(ふつう・よろこび・食事・ねむい・だらしな)。動画用の素材は、アプリの画面をそのまま録るのがいちばん早い。

1. パソコンのブラウザでアプリを開き、画面の幅をスマホと同じくらいに狭める
2. 画面収録でサボリーヌの部分だけを録る
3. CapCutに取り込み、拡大・傾き・跳ねる動きをキーフレームで付ける

姿の切り替えは、記録やありがとうを実際に操作すれば起きる。作り込むより、実際に使っているところを録るほうが速く、しかも本物になる。

## 第1週: 4本の柱を1本ずつ

### 1. ふたりがサボると、こうなる犬

| 時間 | 画面 | テロップ |
| :-- | :-- | :-- |
| 0.0〜1.5秒 | だらしな姿のサボリーヌを画面いっぱいに。寝ぐせのあたりへ寄る | ふたりがサボると、この犬はこうなります |
| 1.5〜5秒 | だらしな姿のまま、おもちゃが散らかった部屋をゆっくり見せる | 寝ぐせ。ぐうたら。散らかったおもちゃ |

| 17〜20秒 | ふつうの姿で静止 | プロフィールのリンクから、里親になれるよ |

キャプション: ふたりがサボると、だらしなくなる犬を飼っています🐕 直し方は、どっちかが家事を1回するだけ。
ハッシュタグ: #同棲カップル #同棲生活 #家事分担 #カップルアプリ #サボリーヌ

## 第3〜4週: 反応の良かった柱に寄せる

第2週の終わりに、保存率とプロフィールへの遷移率の中央値を出す。そこを基準に、上回った柱へ2本ずつ寄せる。以下は「だらしな化」と「ありがとう」が伸びた場合に用意する2本である。伸びた柱が違えば、その柱の続編に差し替える。

## 出したあとに見るもの

判定の基準は docs/sns.md の KPI に従う。1本ごとに一喜一憂せず、第2週の終わりにまとめて中央値を出し、そこから寄せる柱を決める。

投稿のたびに記録するのは3つだけでよい。保存数、プロフィールへの遷移数、コメントの中身である。再生数は柱の良し悪しを判定する材料にならないため、順位付けには使わない。
